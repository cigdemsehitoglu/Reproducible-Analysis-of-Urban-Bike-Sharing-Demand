# Reproducible Analysis of Urban Bike-Sharing Demand

**Peak Hours, Weather Effects & Missing Data Imputation**

Created: October 7, 2026

## What this is
A fully self-contained interactive HTML report analyzing bike-sharing demand patterns.

- Interactive Plotly charts (histogram, hourly patterns, weather effects, imputation comparison, temperature scatter)
- Realistic simulated hourly data for 31 days
- Comparison of missing-data imputation methods
- Clean modern dark theme

## How to view
Just open `index.html` in any modern browser. No R, no Python, no installation needed.

## Deploy to GitHub Pages
1. Create a new public repository on GitHub
2. Upload `index.html` (and this README if you want)
3. Go to **Settings → Pages**
4. Source: Deploy from branch `main` / folder `/ (root)`
5. Save and wait ~1 minute
6. Your live link will appear on the Pages settings page

## Topic
Completely original analysis of urban bike-sharing demand (not activity monitoring, not solar system).
